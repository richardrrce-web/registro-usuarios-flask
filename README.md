# Sistema de Registro Local con Python y Flask

¡Hola! Este es uno de mis primeros proyectos como desarrollador Back-end. Es una aplicación web dinámica que conecta una interfaz de usuario (HTML/CSS) con un servidor en Python, almacenando la información en una base de datos relacional.

## 🚀 Características
- **Backend:** Desarrollado con Python utilizando el micro-framework **Flask**.
- **Base de Datos:** Uso de **SQLite** para el almacenamiento persistente de datos de forma local.
- **Frontend:** Vistas dinámicas renderizadas con el motor de plantillas **Jinja** integradas en HTML5.
